\subsection{Design Flow}

The design methodology adopted throughout this project is based on
progressive refinement.

The architecture is first studied using ideal functional elements in
order to isolate its fundamental behaviour from device non-idealities.
Once the intended behaviour is understood and validated, the ideal
blocks are progressively replaced by transistor-level implementations.

Finally, the complete design is evaluated across process, supply and
temperature variations before layout and post-layout verification.
